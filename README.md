# nostalgic-judge

Entry for the make.fun bounty **"Make the AI Judge Feel Nostalgic: A Childhood
Memory"** (`u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363`).

`main.ts` writes a single sentence — one quiet, specific childhood memory,
at most 280 characters — to `/output/entry.txt`. Deterministic, stdlib only,
no network, no clock, no randomness.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
